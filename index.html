SEC.02

六件趁手的工具

没有云同步、没有账号体系、没有订阅制。就是一套把「整理」这件事做透的本地工具。

01

用途分类Purpose-first

不止按扩展名分堆——按「你拿它做什么」归入 8 个编号目录。内置 200+ 中文关键词规则（合同、周报、课件、发票……），也支持自定义规则与置信度提示。

02

重复检测Deduplication

先按文件大小分组、再算 MD5 指纹，「下载了三次的安装包」无所遁形。GUI 里可逐组勾选，一键移入 _duplicates/ 隔离区而非直接删除。

03

命名引擎Naming Engine

日期后缀、数字前缀、模板化命名、Windows 安全清洗、冲突语义化 _v2。规则全部可配置——详见下方 SEC.03。

04

双主题 GUITrue Dual-theme

深色 / 浅色不是换个壳——所有控件登记入主题注册表，切换时统一重绘。五个标签页：整理、查重、分析、规则、日志，快捷键齐全。

05

命令行自动化CLI & Cron

GUI 能做的 CLI 全能做：organize / analyze / cleanup / rename / naming。配 Windows 计划任务，每天下班前自动整理一次。

06

安卓整理Android via ADB

手机连上电脑，phone organize 直接整理 /sdcard/Download；phone backup 把 DCIM 相册批量拉回电脑。同一套分类与命名规则。

SEC.03

一个较真的命名引擎

文件名是整理工具最容易敷衍的地方。归序在这里修掉了真 bug，也立下了真规矩。

A数字前缀，位数对齐

1_工作目录  2_学习资料
01_工作目录  02_学习资料

同批目录统一补齐到相同宽度，资源管理器里按名称排序即按用途排序。

B日期识别，不误判流水号

订单20240512001.xlsx → 订单_20240512.xlsx
订单20240512001.xlsx → 订单20240512001_20261021.xlsx

数字边界 + 月日合法范围 + 年份 1970–2099 三重校验；日期来源可选文件名 / EXIF / 修改时间 / 创建时间。

CWindows 安全清洗

报告 草案?.pdf
报告 草案_20261021.pdf

非法字符 <>:"/\|?* 替换、结尾点与空格剥离、保留设备名（CON/PRN/NUL/COM1）规避、全角转半角、超长截断且保住扩展名。

D冲突语义化 + 模板可配

{name}_{date}报告_20261021.pdf
{date}_{name}20261021_报告.pdf
{category}_{name}_{date}01_工作目录_报告_….pdf
冲突时报告_v2_20261021.pdf

冲突标记从时间戳改为 _v2 / _v3，插在日期后缀之前；五种模板预设，GUI 与 CLI 均可切换。

SEC.04

PC 上的 GUI，手机上的 ADB

点右边的开关，亲眼看看「真正的双主题」——不是换一层皮，是每个控件都跟着换。

Ordina · 归序 — 整理

安卓手机整理

手机开启 USB 调试连上电脑，同一套分类与命名规则直接作用于手机存储。

  • devices列出已连接的设备与状态
  • organize整理 /sdcard/Download，先预览再执行
  • backup把 DCIM 相册批量备份到电脑
  • cleanup清理临时文件与空目录
  • diagnose存储占用全面诊断报告

SEC.06

三十秒开始

没有安装向导，没有后台服务。克隆或下载源码，三种方式任选其一启动。

WAY 01

双击启动

Windows 下双击项目根目录的启动脚本，直接进入图形界面。

launcher.bat
WAY 02

模块启动 GUI

在项目根目录执行，等价于启动脚本，适合习惯终端的人。

python -m ordina
WAY 03

命令行模式

全部功能无界面可用，配计划任务实现每日自动整理。

python -m ordina cli organize --path ~/Downloads
Python 3.9+ GUI 需 tkinter（官方安装包自带） 依赖 纯标准库，pip 零安装 安卓功能 需 ADB 环境 平台 Windows 为主，CLI 跨平台
